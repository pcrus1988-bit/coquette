# Phase 0 — Workspace & Isolation

This phase creates the safe operating boundary for the COQUETTE rebuild before application code, migration data or production integrations are introduced.

## Exit criteria
- dedicated repository established
- isolated repository structure and security rules established
- dedicated deployment project created
- dedicated staging environment created
- dedicated database/storage selected and provisioned
- backup/restore approach documented
- private Magento migration source area defined
- integration credential ownership recorded
- CI and main protection enabled after stack selection

Until these are complete, production integrations remain disabled.
