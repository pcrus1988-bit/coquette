# Magento Access Checklist — Superseded

**Status:** superseded on 2026-08-26

COQUETTE no longer has administrative/database access to the legacy Magento installation.

This checklist is retained only as historical context for the originally planned conventional migration. It is **not** a blocker and should not be used to request or wait for Magento Admin, database, API, filesystem, customer, order, or media-export access.

The active Phase 4 source strategy is now:

- `docs/migration/STOREFRONT_RECONSTRUCTION_PLAN.md`

The live public storefront at `https://coquetteconcept.gr/` is the recoverable evidence source. Public catalogue, content, media, navigation, attributes, pricing states, bilingual pages and SEO/URL relationships will be captured and reconstructed. Private Magento data that is not publicly exposed must be classified as unavailable rather than guessed.
