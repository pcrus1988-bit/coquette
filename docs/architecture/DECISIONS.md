# Architecture Decisions

Major COQUETTE architecture choices will be recorded here before implementation.

Pending decisions include:
- application framework and repository tooling
- database and ORM/data-access strategy
- authentication and authorization
- product/catalogue domain model
- CMS/content-editing approach
- search
- object/media storage
- checkout/order architecture
- Magento migration method
- payment integrations
- shipping/courier integrations
- AADE/myDATA integration
- observability and backups

Each decision should capture context, selected option, alternatives considered, consequences and migration impact.
