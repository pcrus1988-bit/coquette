# Architecture Gates

Before application scaffolding is merged, the blueprint must answer these gates:

1. Storefront framework selected.
2. Backoffice approach selected.
3. Database selected and isolated.
4. Storage/media strategy selected and isolated.
5. Authentication/authorization model selected.
6. Catalogue/product/variant/inventory model defined.
7. Checkout/order/payment boundaries defined.
8. Content editing/CMS strategy defined.
9. Magento migration strategy defined.
10. Staging and production deployment ownership defined.

Provider-specific production credentials remain out of scope until their integration phase.
